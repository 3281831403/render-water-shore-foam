# render-water-shore-foam

## 题面

湖岸边的泡沫永远浮在半空、涨潮时还会突然消失：负水深没有取绝对值，离岸距离被算成负数；泡沫宽度被写死成 1 米，传入的 width 完全失效；密度沿距离按线性衰减而不是按幂次衰减，岸线附近的泡沫拖得过宽；波相位直接用 t*speed 却忘记除以波长，波峰速度与水面不一致；遮罩里的噪声不随相位变化，整片泡沫像被定格；整帧生成误用了上一帧的深度图，泡沫因此浮在半空；深度衰减在 max_depth 处仍然返回 1，深水区照样冒泡；参数校验漏掉 width<=0，后续计算直接除零；批量生成复用同一张噪声纹理，第二帧与第一帧完全相同；投影 UV 不随相机漂移，岸线死死钉在屏幕上。foam/shore.py 是核心，tests/test_shore.py 15个红。要修的是：岸线贴合、时间连续、深度衰减，以及逐帧独立生成与参数校验，并遵守全部数值契约让 15 个测试通过。

## 运行方式

在仓库根目录执行：

```console
python -m pytest tests -q
```

初始状态下 8 个函数全部是 `raise NotImplementedError` 的桩，应恰好得到 `15 failed`，且不能出现 collection、import 或 syntax error。修复完成后应得到 `15 passed`。

## 契约与约束

- 只使用标准库 `math` 与 pytest；离线运行，不联网，不使用随机数。
- 水深、离岸距离、宽度与波长均以米为单位；水深可以为负，表示水面以上的采样点。
- 一帧推进 1 秒；浮点比较的绝对容差为 `1e-9`。
- 噪声必须由解析式确定性生成，不能依赖进程状态或帧间共享纹理。
- 批量渲染时每一帧都独立计算，不得复用上一帧的噪声或深度。
- 参数表固定包含 `width`、`power`、`speed`、`wavelength`、`slope`、`max_depth`、`camera_speed`。

## tests 不可修改

`tests/test_shore.py` 是验收基准，不可修改、不可跳过、不可放宽容差。所有修复只能落在 `foam/shore.py` 中；`foam/__init__.py` 仅负责导出，不承载实现逻辑。
